# /spec - 设计规范

输出完整的设计规范文档

## 使用方式

/spec              # 输出当前项目设计规范
/spec create       # 创建新的设计规范
/spec update       # 更新现有规范

## 输出内容

完整设计规范包含：
1. 颜色系统（品牌色、中性色、功能色）
2. 字体系统（字体族、字号层级）
3. 间距系统（基础单位、间距规范、页面边距）
4. 圆角系统
5. 阴影系统
6. 组件规范（按钮、输入框、卡片）
7. 响应式断点

## 存储位置

设计规范存储到 `../shared/designs/design-spec.md`
