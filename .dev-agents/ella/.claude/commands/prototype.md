# /prototype - 交互原型

设计用户交互流程和页面状态变化

## 使用方式

/prototype [功能描述]

## 执行步骤

### 1. 理解用户目标
- 用户要完成什么任务？
- 有哪些关键步骤？
- 可能遇到什么问题？

### 2. 绘制流程图
用文字流程图描述用户操作路径，包含成功和失败分支

### 3. 定义页面状态
列出每个页面的状态（初始态、加载中、成功态、失败态、空状态）

### 4. 设计交互细节
表单交互、手势交互（移动端）、动画效果、异常处理

### 5. 输出原型文档
存储到 `../shared/designs/[功能名]-prototype.md`
